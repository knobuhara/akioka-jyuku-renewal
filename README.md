# 秋岡塾 リニューアル プロジェクト

Vue.js + Vite で構築された、秋岡塾用の最新ホームページです。

## 🥋 プロジェクト概要

熊本市の直接打撃制空手道場「秋岡塾」のリニューアル版ウェブサイトです。
モダンで洗練されたデザインを採用し、空手道場の雰囲気を表現しています。

## ✨ 主な特徴

- **モダンなデザイン**: ダークテーマとレッドアクセントを用いた洗練されたUI
- **レスポンシブ対応**: スマートフォン・タブレット・PCに完全対応
- **スムーズなアニメーション**: Vue.jsによる滑らかなインタラクション
- **高速読み込み**: Viteによるビルド最適化
- **サーバーレス**: 静的ホスティング対応

## 🏗️ プロジェクト構成

```
akioka-jyuku-renewal/
├── src/
│   ├── App.vue          # メインコンポーネント（全体レイアウト）
│   ├── main.ts          # エントリーポイント
│   ├── style.css        # グローバルスタイル
│   └── assets/          # 画像・アイコン等
├── index.html           # HTMLテンプレート
├── package.json         # 依存関係とスクリプト
├── tsconfig.json        # TypeScript設定
├── vite.config.ts       # Vite設定
└── README.md            # このファイル
```

## 📦 セットアップ

### インストール

```bash
# 依存パッケージのインストール
npm install
```

### 開発サーバーの起動

```bash
npm run dev
```

ブラウザで `http://localhost:5173` にアクセスしてください。

### 本番ビルド

```bash
npm run build
```

ビルド結果は `dist/` ディレクトリに出力されます。

### プレビュー

```bash
npm run preview
```

ビルド後の本番環境をローカルでプレビューできます。

## 🔧 カスタマイズ

### テキスト・コンテンツの変更

[App.vue](src/App.vue) のテンプレートセクションを編集してください：

```javascript
// 哲学メッセージの例
const philosophyItems = [
  {
    id: 1,
    icon: '🎯',
    title: '稽古は真剣に楽しく',
    description: '何事も楽しむ気持ちを忘れずに本気で取り組もう'
  },
  // ...
]
```

### スタイルの変更

[App.vue](src/App.vue) の `<style scoped>` セクションを編集するか、
[style.css](src/style.css) でグローバルスタイルを変更してください。

### 画像の追加

1. 画像ファイルを `src/assets/` に配置
2. App.vue のテンプレートで参照
